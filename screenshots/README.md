# Screenshots

Genuine screenshots captured on 2026-11-25 from the running application, at a 1440 pixel desktop width in the application's
default dark theme with its own indigo accent. Nothing has been restyled or retouched; some are cropped to one section so they
stay readable.

## How they were made

- The backend and dashboard were run from an **isolated copy** of the private project's working tree, using its normal start
  command, with a fresh database, a fresh data folder and an `.env` that had **no API keys**. The private repository, its real
  database and its real configuration were never opened by the screenshot session.
- The machine name was set to a neutral value (`demo-workstation`) before capture. A page that displays local folder paths was
  cropped to exclude them.
- The footage is a **synthetic test pattern with a tone generated by FFmpeg** (a 90-second video and a 40-second video). No
  third-party or personal footage appears.

## Which parts are real and which are seeded

| Screen | What is real | What is seeded |
|---|---|---|
| Overview, Provider status, Hardware profiles | Everything: live health checks, migrations at head, no keys configured | Nothing |
| Import dialog and Media library | Everything: the import ran through the real job queue (copy, hash, ffprobe, thumbnail) | Nothing |
| Transcript and Moment discovery | The interface, and the rendering and review of the results | **The transcript text and the four moment candidates are synthetic sample records** written directly into the isolated demo database (the technique the project's own tests use). They are labelled "Synthetic-seed" in the interface. **No AI provider was called.** The sample scores are illustrative. |
| Rendered clips and Clip review | Everything: two real FFmpeg renders from the footage, in-page playback, and a real *Approve* click | The moments the clips were cut from |
| Autonomous mode | The source form, the scheduler, and the discovery of one synthetic video in a watched folder | Autonomous mode itself was left **off** (it needs a provider key), so no automatic acquisition, transcription or rendering ran |

## What could not be screenshotted

| Screen | Why it is missing |
|---|---|
| A transcription or moment-discovery *run in progress* | Needs a provider key and consent; none was configured, and no audio or text was sent anywhere |
| Research, content ideas and scripts with real data | Needs feeds and a provider; those pages were not populated |
| A job queue page | **There is no dedicated Jobs page**; job state appears inside the footage and clip panels and in the Overview health list |
| Acquisition from a link or feed | Not run live, so there is nothing to show; the YouTube link dialog was not captured |
| Campaigns with data | The campaign records page was empty and no synthetic campaign was created |
| Channel and niche management | Not populated |
